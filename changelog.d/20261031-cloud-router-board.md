- **`sirsi router board-serve` hosts the router board in the cloud.** The same "Ra — Sirsi work fabric" console (lanes, mailboxes, drill-down) now runs on Cloud Run, reading the canonical ledger, so the owner can open it from any device and no Mac rebuilds the 5 MB snapshot. Cloud-board mode serves only the router surface and its read-only APIs; every workstation endpoint (run, clean, slay, vault, ghosts, stats) returns 404 and non-GET methods return 405. The workstation `sirsi dashboard` is unchanged and still binds loopback only. Refs: ADR-077, ADR-062.
