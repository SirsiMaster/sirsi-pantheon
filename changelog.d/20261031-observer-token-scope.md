- **Read-only observer tokens.** A scoped host token whose scope includes the reserved `@observer` marker may read the whole ledger (ListActive, CountClosed, ListThreads unfiltered, any Inbox and ListTasks, ClassifyLane, OperationalAgents) and register only its own agent's thread; every other method is refused, including Send, close, claim and task writes for its own agent. The marker is a capability, never an identity: nothing can mint, register or act as `@observer`. This is the hosted router board's credential: `sirsi router token mint cloud-board --agents router-board,@observer --secret-resource …`. Tokens without the marker behave exactly as before. Refs: ADR-062, LANE_SCOPED_TOKENS.
