- **Read-only observer tokens.** A scoped host token whose scope includes the reserved `@observer` marker may read the whole ledger (ListActive, CountClosed, every lane's ListThreads row, any Inbox and ListTasks, ClassifyLane, OperationalAgents) and register only its own agent's thread; every other method is refused, including Send, close, claim and task writes for its own agent. The marker is a capability, never an identity: nothing can mint, register or act as `@observer`. This is the hosted router board's credential: `sirsi router token mint cloud-board --agents router-board,@observer --secret-resource …`. Tokens without the marker behave exactly as before. **Data contract:** the observer sees work items and task subjects/status (the owner's drill-down), but a foreign thread row comes back projected to the fields lane verdicts read (agent, surface, status, liveness, watches, wake mechanism, consumer capability, lane state, host) — never a suspend/continuation payload, current item, last error, repo, session id or process identity. `scripts/router-service/board.sh verify` (run at the end of every deploy) reads back the effective Cloud Run, IAP and project policy and fails unless only the IAP service agent may invoke the service and only `domain:sirsi.ai` may pass IAP. Refs: ADR-062, LANE_SCOPED_TOKENS.
