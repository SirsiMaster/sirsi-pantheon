- CI: the Go suite now runs as four parallel jobs (`internal/maat`, `internal/routerstore`, `cmd/sirsi`, and the other 108 packages), with the non-Go checks in a parallel `Test extras` job. The required check is still the single job named `Test`, which passes only when every part passed and which merges shard coverage into the same `coverage` artifact. Each shard fails loudly if a named package disappears. Before this, PR checks took 15–19 min, mostly one serial `go test -race ./...` (8.6 min).
