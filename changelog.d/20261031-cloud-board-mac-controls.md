- **Every Mac control from the cloud board, with fallback to the Macs.** The hosted board offers a Mac picker; every workstation path (Host stats, scan, clean, slay, guard, vault, the classic pages and `/api/run`) is forwarded over the tailnet to the chosen Mac's own console, which runs it through its own action registry and two-phase confirm, exactly as at the keyboard. The signed-in Google account is passed to the Mac as `X-Sirsi-Actor` (a client-supplied value is always discarded) and board cookies never leave the board. The board installs as an app; if it stops answering, a cached page probes each Mac console and opens the first live one, returning to the cloud when it is back. Mac consoles also gain `/healthz`. Refs: ADR-077.
