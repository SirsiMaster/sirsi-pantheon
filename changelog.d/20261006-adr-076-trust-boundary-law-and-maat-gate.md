- **Trust-Boundary Law (ADR-076, Universal Rule 32) and `sirsi maat gate`** (claude-finalwishes-m1, owner-directed 2026-10-06: "fix and rework those gaps once and for all — not just for FinalWishes"). Over 2026-10-05/06 every agent commit in FinalWishes was caught by the security sweep on the same eight defect classes — client numbers as loop/allocation bounds, unbounded output, client-sent provenance trusted, a new path skipping sibling gates, merge-instead-of-replace on persisted PII maps, PII on viewer-readable paths, silent drops and meaning-changing normalisation, and verifiers whose exit status was lost in `… | tail && push` plus self-admitted exemptions. ADR-076 names them A–H as binding law with the checklist every slice reports one line per item; `CLAUDE.md`/`PANTHEON_RULES.md`/`AGENTS.md` §1 gain the identical Universal Rule 32. `sirsi maat gate` (`internal/maat/trustboundary`) runs a repo's traceability verifier as committed at the BASE with its own exit status as the verdict (a verifier edited, added or removed in the range refuses the push — no self-attestation), refuses any hash newly admitted to `scripts/traceability-historical-exemptions.txt` in the range (set difference, so an equal-count swap fails too), runs gitleaks over the range, and lints every Go/TS/shell path that differs at the pushed head (`-z --no-renames --diff-filter=d`: renames-with-edits and non-ASCII names included) as blobs — never the working tree — with A–H heuristics (allowlist `trust-boundary: <reason>`; missing/unreadable blobs and unparsable Go are explicit failures); `--pre-push` evaluates every content-bearing ref on stdin, fails closed on a branch with no resolvable base, and emits JSON only under `--json`, so any repo adopts it with one hook line, `--report` prints the checklist skeleton, `--install` arms `core.hooksPath` (one call covers a repo's worktrees). Fixtures in `testdata/` reproduce each class with minimal Go/TS/shell; the gate test pins that a verifier printing "passed" and exiting 1 still fails the gate. Pantheon's own pre-push now runs the lint on pushed files. Refs: ADR-076, ADR-004, PANTHEON_RULES A6/A7/A17/A28; Changelog: Unreleased
