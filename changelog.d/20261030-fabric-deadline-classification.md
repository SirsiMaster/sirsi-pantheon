Propagate Fabric command cancellation through existing ledger/runtime reads, report fixed-stage deadline attribution without read payloads, and preserve context plus source causes when cancellation races a read. Bound independent per-agent runtime classification to four workers; the helper joins started callbacks before yielding its result and returns no partial map. A command deadline may return its caller while the acquisition worker remains active, and cancellation does not retract remote work already dispatched.
