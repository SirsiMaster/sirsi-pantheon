# Stack Lab Native Surface Catalog

**Recipe:** `stacklab.recipe.native-stacklab-surface`  
**Product:** Sirsi Pantheon macOS app

The native Stack Lab view is a functional projection of `sirsi stacklab doctor
--json`. It shows the canonical declared-roster result, typed authority defects,
and unreadable canonical sources without translating them into a false green
state. Every incomplete result can continue into Ma'at for evidence review.

It does not publish a wing, pin a registry record, create a release, or execute
an arbitrary shell command. Those are distinct reviewed workflows. This keeps
Stack Lab a real product surface while retaining one Go authority for registry
semantics.

The machine-readable source/test/dependency boundary is
[`contracts/stacklab/native-stacklab-surface-recipe-v1.json`](../../contracts/stacklab/native-stacklab-surface-recipe-v1.json).
