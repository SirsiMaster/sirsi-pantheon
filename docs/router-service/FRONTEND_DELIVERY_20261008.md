## Operation and rollback

One user LaunchAgent, `ai.sirsi.router.surface`, starts the exact immutable frontend executable with `dashboard --no-open --port 9119`, fixed canonical repository working directory, and `SIRSI_ROUTER_URL=spool:///var/sirsipantheon/relay`. Launchd restarts a failed process and starts it at login. No privileged helper, admin dialog or authentication script is used.

Open `http://127.0.0.1:9119/router`. The manifest exposes the running source/build identity. Unconfigured producer returns 503; collection failure returns 502. The UI retains a failed refresh only with its original timestamp and an explicit stale/unavailable banner, never silently relabeling it live.

Rollback: boot out only `gui/501/ai.sirsi.router.surface`; preserve its binary and plist as evidence. Router relay and agent supervision remain unchanged. Redeploy a new immutable binary by updating this one LaunchAgent, not a second dashboard.
