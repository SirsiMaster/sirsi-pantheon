# PRD — Ma'at System One

## Product job

Provide a local, evidence-linked quality and governance layer: assess facts, append decisions, and expose a deterministic Casebook projection through CLI and API surfaces.

## Boundaries

Ma'at does not require an LLM, remote telemetry, or a copied router database. It must not infer authorization from missing evidence, silently mutate a case, or claim remote attestation from a local record.

## Local recurrence intake

When an operator observes a new recurring failure, Ma'at records a typed, create-only local proposal rather than editing a checked-out catalog. The native Ma'at Proposals workspace and the CLI expose the same queue, creation confirmation, retry state, and Stack Lab review route. A proposal is not a matcher, repair, or release authority: only reviewed Stack Lab promotion may change shipped recognition.

## Done

Assessment semantics, append-only decision records, deterministic projection, and explicit failure states are source-defined. Current release, host, and cross-device proof remain traceability rows rather than implied completion.
