# User stories — Ma'at System One

- As an operator, I can run an audit and see facts, determination, explanation, and evidence links.
- As a reviewer, I can inspect an append-only decision and distinguish local evidence from remote attestation.
- As a fleet operator, I can see reservation, contention, handback, and failure records without them being treated as grants.
- As a maintainer, I can update one recipe component with its own tests and receipt.
