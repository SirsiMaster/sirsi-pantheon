# User stories — Pantheon PT

- **PT-US-01** — As an operator, I use the same engine from supported surfaces.
- **PT-US-02** — As a maintainer, I trace assets to exact source/retained bytes.
- **PT-US-03** — As a release owner, I distinguish source/unsigned/signed/notarized,
  published and actual installed/loaded evidence.
- **PT-US-04** — I install/upgrade/roll back/uninstall without unrelated mutation.
- **PT-US-05** — I open one coherent native app/menu bar, select a workspace,
  navigate by keyboard and retain my place with clear empty/loading/error states.
- **PT-US-06** — I fix a finding inside Pantheon and see actual effect/postcheck,
  or follow retained recovery without replaying an unknown action.
- **PT-US-07** — I search/classify evidence and use Ma'at without requiring an
  LLM, remote service or paid outside intelligence.
- **PT-US-08** — I inspect a recipe's components, dependencies, source, replacement
  boundaries and evidence before selection/test/execution.
- **PT-US-09** — I see qualified Apollo/Mercury/Horus/Ra information, distinguish
  fresh/stale/unknown and follow a supported remedy.
- **PT-US-10** — I inspect certification, release proof and remaining work through
  canonical records and human reading locations, without relying on an agent.

Each story includes failure/cancellation/retry/recovery where applicable. These
are acceptance requirements, not installed success claims. `CERTIFICATION.md`
and `DIAGRAM_INDEX.md` identify owners, process mappings and proof.
