# Pantheon PT — Stack Lab canon

This directory is the authoritative Pantheon PT Stack Lab canon. It records
source, release, package, cask, remote-promotion, native-operation and custody
boundaries. It does not claim signing, notarization, cask installation,
installed-host qualification or whole-wing certification that has not been
evidenced.

## Process and diagram canon

- [`DIAGRAM_INDEX.md`](DIAGRAM_INDEX.md) is the process denominator and links
  each stable process ID to requirements, stories, source, evidence, owner,
  implementation state and the applicable Mermaid views.
- [`DIAGRAMS_RUNTIME_NATIVE.md`](DIAGRAMS_RUNTIME_NATIVE.md) covers the engine,
  native app, workspace and observation processes.
- [`DIAGRAMS_ROUTER_MAINTENANCE.md`](DIAGRAMS_ROUTER_MAINTENANCE.md) covers
  router workers, MCP, evidence custody, pressure and relay maintenance.
- [`DIAGRAMS_RELEASE_EVIDENCE.md`](DIAGRAMS_RELEASE_EVIDENCE.md) covers
  package, updater, cask, publication, install/rollback and evidence flows.
- [`DIAGRAMS_MAAT_STACKLAB_LOCAL.md`](DIAGRAMS_MAAT_STACKLAB_LOCAL.md) covers
  Ma’at archive commands and local Stack Lab preference/catalog workflows
  PT-P29–PT-P40. The 40-row index is an audited scope, not a whole-wing
  completeness or certification claim.
- [`TRACEABILITY_MATRIX.md`](TRACEABILITY_MATRIX.md) remains the requirement to
  evidence record; diagram presence is structural documentation, not test,
  qualification, release or certification evidence.
