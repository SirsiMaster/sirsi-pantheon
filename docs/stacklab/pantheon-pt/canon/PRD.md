# PRD — Pantheon PT

## Product job

Deliver one Pantheon engine across CLI, TUI, MCP, native Swift app, one menu bar,
retained local dashboard, package and release surfaces. Users diagnose a problem,
understand its cause, review and execute a bounded remedy through the application,
and see verified resolution or actionable retained recovery. Command exit alone
does not prove resolution.

## Commercialization gate

- User: Mac owners/developers operating local AI and software workloads.
- Pain: pressure, stale processes, unresolved diagnostics and divergent versions
  force users to repair the tool itself.
- Workflow: observe → understand → review → fix → verify → retain evidence.
- Value: reliable free local resolution earns adoption. Models/fleet capabilities
  are optional, not baseline prerequisites. No unmeasured JEV comparison is made.
- Trust: local-first, explicit effect consent, least privilege, one state, no
  hidden remote dependency or credential disclosure.
- Operations: Main owns PT source/canon; SSA release/selected runtime adoption;
  Ra and upstream owners retain their qualified responsibilities.
- Done: every applicable requirement has independent integrated proof. Missing
  evidence has an owner/action, not invented credential or approval blockers.
