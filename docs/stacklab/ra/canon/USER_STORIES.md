# User stories — Ra / Horus Fabric

- As an operator, I can see worker, task, lease, health, and evidence state in one read model.
- As a worker, I can claim a task with an expiring fenced lease and return a proof-backed result.
- As a reviewer, I can distinguish assigned, working, blocked, stale, and complete states.
- As a maintainer, I can add a provider adapter only with conformance tests and lifecycle evidence.
- As an operator, I can tell whether a result is source-tested, host-observed, or
  live-service verified without reading a prose promise.
- As a Codex worker, I can work through the host relay without receiving the
  router token or a copy of the canonical database.
- As a release maintainer, I can build, verify, publish, and roll back the
  router client/service from one hash-bound recipe.
