# Ra / Horus Fabric — Stack Lab canon

This directory is the authoritative Ra router wing. It contains the product,
architecture, design, plan, operations, security, quality, component and
release contracts. The source authority remains the Pantheon router and its
canonical GCP service; Stack Lab documents do not create a parallel registry,
router database, or release channel.

Read in this order: `PRD.md` → `ARCHITECTURE.md` → `DESIGN.md` → `PLAN.md` →
`RUNBOOK.md` → `RELEASE.md` → `TRACEABILITY_MATRIX.md`.

Every claim is labelled source-bound, locally verified, live-host verified, or
open. A green source test is never silently promoted to live fleet evidence.
